# mat-2110-github-assignment
Pull: Fetches changes from a remote repository and immediately merges them into your current local branch.
Fetch:Downloads new commits, branches, and files from a remote repository without automatically merging them into your local work.
Push: Uploads your local committed changes to a remote repository so others can see and access them.
Merge: Combines the commit history and changes from one branch into another, such as bringing a feature branch into `main`.
Commit: Saves a snapshot of your staged changes to the local repository's history along with a descriptive message.
Fork: Creates a personal copy of someone else's repository under your own GitHub account so you can experiment freely without affecting the original project.
Clone: Downloads an entire remote repository and its full commit history onto your local computer.
Branches: Independent lines of development that let you work on new features or bug fixes in isolation from the main codebase.
